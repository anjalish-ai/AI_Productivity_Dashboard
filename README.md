# AI Productivity Dashboard

A modern React-based productivity dashboard that combines tasks, notes, AI suggestions, and widgets into a single interface.

## 🚀 Features
- ✅ Task Management (add, delete, mark complete, saved)
- 📝 Notes system with localStorage
- 🤖 AI Suggestions (smart frontend logic)
- 🌦️ Weather widget (API integration)
- ⏰ Reminder widget
- 🎨 Modern UI with custom theme

## 🛠 Tech Stack
- React JS
- CSS
- Axios
- LocalStorage

## 📌 Project Type
Frontend Simulation (SaaS Dashboard)
